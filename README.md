# Finance reconciliations

Open the hosted website in a current desktop browser, or download the static files together and open `index.html`. Users can select Excel files and generate a workbook without installing software. Use the navigation to switch reconciliations.

The application processes source files in the browser. Keep organization-specific profiles, original exports, and completed workbooks in your internal file location. Distribute profiles separately from this repository. The application loads LoanStreet mappings for the current page session.

Before downloading an Excel workbook, enter the preparer's initials and actual completion date. The workbook includes a Completion record sheet. Suspense writes both fields on the cover. When a supported destination cover is available, the output also lists the original paste cells.

Transaction dates in the copy-ready matchup and carryover sheets are Excel date values. Use Paste Values to retain the destination workbook's date format.

On Wisdom trial balance forms, **Detect trial balance columns** recognizes the native Consolidated Trial Balance Report and also checks for account and ending balance headings. Verify the report period and suggested columns. For multiple LoanStreet workbooks, the suggestions must agree across all files.

## LoanStreet

1. Drop a completed consolidated LoanStreet workbook or your local JSON profile to supply the pool, account and worksheet mappings. A completed workbook must include the paired covers and details and populated balance cells. Choose the month and drop the Buy Side Combined Report.
2. To include ledger balances, drop the month's Wisdom trial balance workbook or workbooks. Select the worksheet, G/L account and ending balance columns, and data row range. Multiple workbooks must share the mapped column layout and together contain each required account once. Verify the period and confirm the balances reflect the month-end entries.
3. For exact detail paste addresses, prepare the current month's blocks in a copy of your existing workbook and select it under **Prepared detail sheets**. Include the year in new headings to check it automatically. **Detail inputs** shows existing numeric values and the proposed change. **Cover period inputs** lists the cover titles to update when the prepared workbook contains recognizable title cells.
4. Download the workbook. Copy the identified KEY INFO, cover, and detail values into your current monthly worksheets. **Cover audit inputs** lists the preparer initials and Excel date cells on recognized pool and payable covers. Review existing formulas, adjustments, and exceptions in your destination workbook.

## Teller Vault

1. Choose the month and drop the Daily EOD log and Wisdom trial balance. If you have reviewed the closing total directly, select **Enter the verified closing total** and enter the date and amount. The download records how the value was entered.
2. Select the worksheets and input columns. For a single-account Wisdom report, select its verified ending-balance cell. Verify that the log contains the final closing entry and that the Wisdom report covers the selected month.
3. Drop the prepared monthly MV workbook to read its main vault G/L account and in-transit adjustment. Alternatively, enter the account, signed adjustment and description. Confirm, download the results and paste values into the indicated MV cells.

## Corporate Card

1. Choose the month and review the effective-date range. The default includes the first day of the next month.
2. Drop the card account history (.xls or .xlsx) and verify the effective date, transaction code, signed amount, and description columns. Add the prior reconciliation with **Pending Charges** or the previous download with **Open items**. Review the inferred columns and data bounds.
3. Load the rows. Review duplicate and boundary-date items. **Suggested pairs** lists every unique exact funding and charge amount. Select a pair and verify both descriptions before matching. You can also select one open row to look for a unique exact split across two opposite rows, or select related rows yourself. Exclude entries already used in an earlier reconciliation.
   Check the pairs you want in **Suggested pairs** and choose **Match checked pairs**. Each checked pair becomes its own group. An exact, unique opening-day match to a previously matched row in the prior app download starts excluded. Review the prior source cell and reopen the row if appropriate. Matches found in a legacy Matchup sheet or with duplicate candidates are flagged for review.
4. Optionally drop the prepared **Corp Card** cover. If it is omitted, a supported cover in the prior workbook supplies the same paste locations. The download lists the audit cells and the posted closing balance paste cell when the history reaches month-end.
5. Confirm carryovers explicitly, including any standing historical items. **Open items** contains confirmed carryovers for the following month. **Unmatched activity** contains everything still waiting for a match or a review decision. Use **Pending Charges** for confirmed positive funding rows and verify that the destination total includes every pasted row.

## Cashier's checks

1. Choose the month. Enter the closing account balance or drop the CUSA ending-balance workbook and select its verified cell. Enter the signed line item total or drop the prepared current-month reconciliation to read its reviewed line items.
2. Drop the draft history workbook and verify the suggested date, transaction code, reference and signed amount columns. For confirmed reference corrections, paste the draft worksheet row number and correct reference. The download records both values in **Reference corrections**.
3. Drop the prior reconciliation with its **Checks Outstanding** tab. The recognized cover must show the preceding month. Confirm an empty opening list only when there are no prior outstanding checks.
4. Compare checks and download the proposal. **Opening checks** gives the copied-forward list before current activity. Review matches and exceptions, then use **Checks Outstanding** for the proposed closing list. Use **Paste cells** for the closing balance and **Cover audit inputs** for the initials and date. Extend the destination total if the new list is longer. Copy the monthly draft history block into the existing workbook.
   For a reviewed exception, paste the draft worksheet row and **Carry** or **Exclude**. Carry keeps a confirmed issue outstanding. Exclude keeps the row out of the paste block and records the action in **Reviewed draft decisions**.

The comparison matches unambiguous references and amounts for positive SU issues and negative DF clearings. Unresolved prior checks stay in the proposed opening list. Review other codes, conflicting references and differences in the Exceptions sheet.

## VIZO settlements

1. Choose Overnight Settlement, PSA, PCC, MISC, Charge Cards, Settlement or ATM Debit Card Settlement and select the month. Each choice downloads its own cover and review sheets.
2. Drop the provider Transaction Summary CSV or Excel export. Map its date, description and signed amount columns. For Overnight Settlement with no provider activity, confirm the empty month and provide the verified statement balance separately.
3. Drop the native Wisdom Detailed Trial Balance for the account to validate running balances and pick the last balance through the selected month end. For a reviewed G/L History table, map the transaction columns and supply the verified closing balance. ATM needs activity from the prior month's final days. For opening dates outside the main report, load the prior Wisdom history or select the reviewed ATM Matchup worksheet. The download identifies archived rows for review.
4. The native VIZO Transaction Summary CSV supplies the transaction columns and closing balance. Review the closing row and adjustments. For Charge Cards, review the proposed statement-side LoanStreet adjustment from the current month's LS journals. A separate LoanStreet history or a reviewed manual amount is also supported. For Settlement, verify the branch offset and include the first business day of the next month in the primary file or a separate Settlement CSV. The separate file must continue the same account's running balance. Identical overlapping transactions are counted once, and the new rows contribute only to cutoff review. Review exact branch and mobile deposit candidates before updating carryovers.
5. Review the account-specific schedules in the downloaded workbook. For ATM, the date range between consecutive provider batches gives the candidate ledger dates for weekends and holidays. Review every multi-day batch against IF-67 even when its total agrees. To include IF-67 in the download, drop reviewed daily totals in Excel and map one row per ledger date with signed settlement and ISA amounts. For Settlement, review share drafts, branch capture, mobile capture, returned deposits and the month-end branch carryover. Use a reviewed classification column for generic forward collection descriptions. For PSA and PCC, review the interest and transfer entries. For Charge Cards, review billing, money orders, cash advances and LoanStreet carryover. Use Overnight Settlement's opposite-signed totals to prepare its posting review.
6. For MISC, review the card funding suspense, overdraft and transfer sheets. The Reconciliation tab follows the MISC cover's balance and difference cell positions and carries the signed total of reviewed in-transit items. Keep your reviewed individual line items in the existing workbook.
7. Use **Cover paste cells** for the statement balance, ledger balance on the selected sign basis, and the preparer's initials and date. The sheet names and cells follow the historical covers for each account. Apply the reviewed in-transit items in your existing workbook and recalculate its difference formula.
8. On Charge Cards, drop the prior month's LendKey invoice PDF. The importer checks the line items, tax and amount due and lists exact VIZO billing debit and Wisdom posting candidates. Review candidates before posting or clearing an invoice.

## LendKey

1. Choose the month. For ACH, drop the provider workbook and the Fed activity reviewed for LendKey. A combined Fed workbook can include a **Finance provider** column. When present, only rows labeled LendKey are used. The standard LendKey report selects and maps its ACH worksheet automatically. Verify the source columns, dates and direction convention. The settlement date determines the comparison date when supplied. Rows on the standard worksheet without an ACH date or direction are retained in ACH source review and held out of cash totals. Map an exclusion-reason column for any additional reviewed exclusions.
   The tool checks same-date totals first and then matches unique batches by exact amount and comparison direction across the selected dates. ACH batch matches lists the dates and source rows. Repeated amounts without a unique match remain open. To use a confirmed posting date in daily totals, paste the provider ACH date, reported direction, and confirmed Fed date. Amounts Lineup groups the standard provider's loan-level rows for copying.
2. Drop the monthly LendKey PDFs for Consolidation, Home Improvement and Student. The browser checks the statement month and lists each imported line in **Statement paste cells**. A roll-forward appears for each schedule with enough inputs. Add the prepared workbook to supply amounts the PDF does not identify, including the remaining Home Improvement lines. You can also drop the standard Home Improvement workbook to extract supported inputs from **Recon Adj Wkbook**. The site uses it automatically if the standard workbook is loaded in the ACH section without a Fed file.
3. Enter any reviewed prior A/R and A/P balances and new in-transit or late-fee amounts by product. Prepare the draft and download Excel. Use **ACH date review** before pairing individual rows in the monthly **Amounts Lineup** block.
4. Review **Purpose Matchup**, **Purpose totals** and **Carryover review**. The tool stages statement amounts separately. It suggests a prior clearing only if exactly one combination of one to three eligible payment rows matches the amount for the same product and direction. The search covers up to 120 eligible rows. Confirm against the source statements and review which amounts belong in each cash subtotal before pasting the left-side Purpose Matchup rows.
5. Optionally drop the verified Wisdom trial balance and map its G/L and ending balance columns. The tool takes the account mappings from the prepared workbook's Cover Page formulas. Review, recalculate and save the CUSA Entries before uploading the prepared workbook.
6. Copy the values listed in **Statement paste cells** and **Cover balance review** to the indicated cells. Check the calculated statement variances and review the adjustments and differences on the Cover Page.

## Student Choice

1. Choose the month, earliest journal date and matching lookback. Include the prior month's final week.
2. Drop the original weekly CSV or Excel journals, either directly or in ZIPs. Use the manual's Effective Date, transaction code, Amount, PRIN, CINT, INT, CFEES and LATE fields. Identical rows with the same Transaction ID count once. Conflicting values under one ID stay in review. The Excel output uses source rows and omits borrower and transaction identifiers.
3. Drop a reviewed Fed worksheet with Date, Direction, Amount and Description headers. For a combined file, add a **Finance provider** column and label the applicable rows Student Choice. Drop the one-page Student Choice invoice PDF, choose an Excel invoice total cell, or enter the amount manually. The PDF's printed and remittance totals must agree. An optional expected Fed date can distinguish same-amount debits. Review the separate invoice row before copying it below the monthly totals.
4. Drop the prepared monthly **Cover Page** workbook for the cover calculation. You can run it with or without the journal and Fed comparison.
5. To fill the cover from source files, drop the month-end workbook with **Principal**, **Capitalized Interest** and **Interest** tabs. The tool selects the period on tabs with Year and Month columns. For other layouts, choose the verified numeric totals row on each tab. **Provider roll-forward** checks the calculated balances against reported endings, and the app fills the recognized cover refund cell when the statement supplies refunds. Review other manual adjustments in the cover. For Wisdom balances, drop the trial balance and map its account and ending balance columns. The tool reads the two accounts from the cover labels.
6. Download the draft. Review chronological groups, duplicate journal rows, the invoice and other exceptions. Check the group formulas in **MATCHUP**. Paste reviewed values into A–F, H and J of the monthly block and keep its formulas in G. Compare the proposed and saved amounts in **Proposed cover inputs** before updating the monthly cover.

## Federal Reserve

1. Choose the statement date. Drop the day's files together and review the suggested assignments, or use the individual drop areas. Applying a new batch clears omitted inputs from the preceding batch. FedMail Statement of Account text files and text PDFs supply the closing balance, wire and ACH summary amounts. The importer checks debit and credit totals against the closing balance. The native Wisdom Detailed Trial Balance and reviewed Excel or CSV activity tables are supported. Files marked for manual review are listed in the download.
2. Include one Closing Balance row per source or enter each closing balance from the source. Choose the Wisdom transaction sign used for comparison.
3. Optionally select the prepared daily reconciliation with the selected date in MATCHUP, current Ops inputs and reviewed cover line items. Recalculate and save reviewed formula inputs before selecting it. The tool uses the cover's line-item total range and recalculates the linked Ops amount from the current Ops inputs. Without a workbook, enter the signed total of reviewed cover line items.
4. Prepare the draft and download Excel. Compare the separate wire directions, gross statement ACH and net Wisdom settlement. Review the source rows and exceptions. Paste the listed inputs and check the existing cover and matchup formulas. For the recognized daily cover, **Cover audit inputs** lists where to paste the preparer's initials and completion date.
5. To include **VIZO MATCHUP**, drop the VIZO Settlement Transaction Summary and Wisdom Detailed Trial Balance or reviewed activity tables. The tool follows the template's same-row share-draft, suspense and return formulas and its next-row branch and mobile deposit formulas. Review **Deposit allocation candidates** for generic forward collections. Paste the first four columns of the rows you confirm into the reviewed allocations field and prepare again. A confirmed allocation whose Wisdom date differs from the template remains in review. Label confirmed suspense items Share Draft Suspense. Include a zero No activity row on a confirmed empty date. Use **Clearing review** for unresolved share-draft differences and returned deposits, then copy the reviewed values to the listed cells.
6. Include the next Wisdom finance posting date in the Fed G/L export. The posting date defaults to the next weekday and is editable for holidays. Recognized provider ACH debits and credits posted on that date enter the current Fed Rec's ACH total and proposed Finance columns. Use a `Finance provider` column for additional reviewed providers or ambiguous descriptions. **Finance timing** shows each posting date and source row. **Finance cover review** lists signed totals by provider and direction for checking against the prepared cover.
7. After LendKey or Student Choice posts, keep the original Wisdom balance in the daily inputs. Use **Check the cover after provider reconciliations post** to load the refreshed balance for the same date and confirm the posted providers. The check compares the Wisdom balance movement with the selected cover timing items and recalculates the cover. When both agree, **Refreshed cover paste cells** lists the updated balance and the exact items to clear.

## CD investments

1. Choose the month and drop any of the prepared principal, receivables or CD interest templates. Confirm the current roster before running.
2. For balances, load the Wisdom trial balance and map the G/L and ending balance columns. Review **Saved ledger comparison** before pasting. For the principal comparison, load reviewed provider balances keyed by issuer or G/L and enter the signed line items total. If several positions share one account, provide a distinct Position ID for each row. The draft compares available provider balances by account and lists missing inputs. Principal statement paste cells and comparison totals appear once the mapped accounts are covered.
3. For interest, choose the posting date. The tool follows the supported formulas in the CDs sheet and lists rows requiring review.
4. Download the workbook. Review principal differences, provider positions and unmapped balances, then use **Paste cells** to update the monthly copies. Review active interest exceptions and the separate list of matured rows with blank interest cells.
5. For an independent receivable comparison, drop the provider's Excel or CSV balances with an Accrued Interest column and G/L account or issuer. The output compares those amounts against Wisdom in **Receivable comparison**. The original receivable cover still receives the Wisdom balances in its existing input cells. **Paste cells** also lists the preparer initials and completion date for recognized principal and receivable covers.

## Suspense accounts

To prepare the batch, load the local suspense profile and choose the period. Upload the month-end Excel trial balance and verify its worksheet, account column, closing balance column and row range. The import uses a zero expected balance and flags differences and ATM timing items for review. To enter reviewed adjustments in the batch, use the paste option. Paste G/L account and ending balance, followed by optional expected balance, signed adjustment, description, and reviewed ATM cutoff date. The ATM transfer offset is applied only when a cutoff date is supplied.

Review the matched, missing, and unresolved accounts. Download the ZIP and extract one Excel workbook per matched account. Each workbook has the suspense cover layout, with the ledger balance in K10, difference in K25, and preparer initials and date in K34 and K35. An optional `names` object in the local profile can override the cover title for each workflow key.

Select the account and month. Enter the G/L account manually or load a local profile. Upload the Wisdom trial balance or select the verified M490 closing-balance row when the workflow calls for it. Confirm the expected balance, including a nonzero target where applicable.

For ATM transfers, the worksheet stages an offset against the selected ending balance. Check the editable timing date, which starts at the preceding month-end. For ATM exceptions, optional VIA Offload and IF-67 Excel extracts use Date, Reference, and Signed Amount columns. The Trace review tab lists unmatched items, duplicates, and amount discrepancies for investigation. Review the source balances and paste values into your existing workbook's corresponding fields.

## Static deployment

Run `node build.mjs` to copy the allowlisted website assets to `dist/`. Serve that folder from a static host with `index.html` as the entry point. The same files work offline when kept together. Browser imports and downloads require no API keys or external spreadsheet service.

The bundled PDF.js 5.6.205 display and worker assets come from the upstream `pdfjs-dist` package under the included Apache 2.0 license. Their minified module builds are wrapped as classic scripts for opening the portable HTML directly. The wrappers remove the terminal module exports and supply the script URL in place of `import.meta.url`. The LendKey importer uses the bundled parser for local text extraction.
